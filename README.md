# hugolify-theme-projects-tags

## Install

Edit `config/_default/module.yaml` to install the `hugolify-theme-projects-tags` module:

### V2

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-projects-tags/v2
  - path: github.com/hugolify/hugolify-theme-projects/v2 # required
  - path: github.com/hugolify/hugolify-theme/v2 # required
```

### V1

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-projects-tags
  - path: github.com/hugolify/hugolify-theme-projects # required
  - path: github.com/hugolify/hugolify-theme # required
```
